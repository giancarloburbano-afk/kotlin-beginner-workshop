Taller para principiantes de Kotlin.

Este repositorio contiene ocho ejercicios desarrollados en Kotlin como parte de un taller de programación, para practicar los fundamentos del lenguaje con diferentes problemas de programación. 
Estructura: lista de exercise-01 a exercise-08, cada uno con su Main.kt. 
Ejecución: clonar el repositorio, abrir en IntelliJ, entrar a la carpeta del ejercicio, abrir Main.kt y ejecutar. 
Requisitos: IntelliJ y entorno compatible con Kotlin.
